# Doorman landing page

Smoke-test landing page for Doorman, Team 9's AI access-approval copilot (CS177, Fall 2026).

- `doorman.html` is the page source. It is also published as a Claude artifact.
- `index.html` is the GitHub Pages site. Rebuild it with `./build.sh` after editing `doorman.html`.
- Sign-ups on the public site go to the team's Google Form.

Earlier versions live on the `v1-clearance` and `v2-doorman` branches.
